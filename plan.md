# Solving ∫x² dx — Manim Video Plan

## Narrative arc
The viewer first sees integration as accumulated area under `y=x²`, then connects that geometry to the power rule. The “aha” is that differentiating `x³/3` returns `x²`, so the antiderivative is verified rather than merely memorized.

## Target
- 16:9, 1280×720, 30 fps production render
- About 35–45 seconds
- No voiceover; concise on-screen captions
- Dark 3Blue1Brown-inspired palette

## Palette
- Background `#1C1C1C`
- Function/input `#58C4DD` (blue)
- Accumulated area/answer `#83C167` (green)
- Rule/highlight `#FFFF00` (yellow)
- Verification `#FF6B6B` (coral)

## Scenes
1. **Question (slow, centered):** Introduce `∫x² dx` and the idea “find a function whose derivative is x².”
2. **Geometry (medium, graph-left / formula-right):** Draw `y=x²`, reveal area from 0 to `a`, then show `A(a)=a³/3`.
3. **Power rule (medium-fast, horizontal derivation):** Raise exponent by one, divide by the new exponent, and add `C`.
4. **Verification (slow conclusion):** Differentiate the answer and land on `x²`; show the final boxed result.

## Key takeaway
`∫x² dx = x³/3 + C`, because `d/dx(x³/3 + C)=x²`.
